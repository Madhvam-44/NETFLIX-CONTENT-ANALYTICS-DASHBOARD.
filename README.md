# NETFLIX-CONTENT-ANALYTICS-DASHBOARD.

1. Short Description

The Netflix Content Analytics Dashboard is a comprehensive Power BI project built to explore and visualize Netflix’s catalog of movies and TV shows. The dashboard provides insights into content distribution, genre popularity, release patterns, ratings, and production trends, enabling users to better understand Netflix’s content strategy and global expansion.

2. Tech Stack

The dashboard was developed using the following tools and technologies:

📊 Power BI Desktop – Used to design interactive reports and visualizations.
📂 Power Query – Performed data extraction, cleaning, transformation, and preprocessing.
🧠 DAX (Data Analysis Expressions) – Created calculated measures, KPIs, dynamic filters, and custom metrics. Some calculations required advanced DAX logic and multiple iterations to accurately represent business insights.
🔗 Data Modeling – Established relationships between tables for efficient filtering and analysis.
📈 Interactive Visualizations – Implemented slicers, cards, charts, maps, and drill-down capabilities for enhanced user experience.
📁 File Format – .pbix for development and .png for dashboard preview images.
📂 Data Source

The project uses a dataset containing information about Netflix movies and TV shows.

3. The dataset includes attributes such as:

Movie and TV show titles
Genre classifications
Release years
Content ratings
Country of origin
Duration
Directors and cast information
Date added to Netflix
Show type (Movie or TV Show)

The data was analyzed to identify trends in Netflix’s content library and understand viewing and production patterns.


 4. Business Problem

With thousands of titles available across multiple countries and genres, it becomes challenging to manually identify content trends and understand how Netflix has evolved over time.

Key business questions include:

How has Netflix expanded its content library over the years?
What is the distribution between Movies and TV Shows?
Which genres dominate the platform?
Which countries contribute the most content?
What are the most common maturity ratings?
How has content addition changed over time?

Without an interactive analytical solution, extracting these insights can be time-consuming and inefficient.

🎯 Goal of the Dashboard

The objective of this dashboard is to build an intuitive analytics solution that:

Provides a clear overview of Netflix’s content catalog.
Tracks growth in content releases over time.
Compares Movies and TV Shows across multiple dimensions.
Identifies popular genres, ratings, and production countries.
Enables users to interactively explore content trends using filters and slicers.


5. Walkthrough of Key Visuals

🔹 Executive KPIs

The top section highlights important metrics such as:

Total Titles
Total Movies
Total TV Shows
Number of Genres
Countries Represented
Content Ratings Covered

These KPIs provide an instant snapshot of Netflix’s overall content library.

🔹 Movies vs TV Shows Distribution

A comparison chart illustrating the proportion of Movies and TV Shows available on the platform.

🔹 Genre Analysis

Interactive visuals displaying the most common genres and helping identify audience-focused content categories.

🔹 Country-wise Content Distribution

Geographical analysis highlighting which countries contribute the highest number of titles to Netflix’s library.

🔹 Ratings Breakdown

Visualization of maturity ratings (such as TV-MA, PG-13, TV-14, etc.) to understand content suitability across different audiences.

🔹 Interactive Filters

Users can dynamically filter the dashboard by release year, content type, country, genre, and rating to perform customized analysis.

6. Business Impact & Insights

   Content Strategy Analysis

The dashboard reveals how Netflix has continuously expanded its library while diversifying content across genres and regions.

   Genre Popularity

Certain genres consistently dominate the platform, indicating strong audience demand and strategic investment.

   Global Expansion

Country-level analysis demonstrates Netflix’s increasing international presence and growing investment in regional productions.

   Audience Segmentation

Rating analysis helps understand how Netflix balances family-friendly programming with mature content offerings.

   Data-Driven Decision Making

The dashboard enables analysts, recruiters, and business stakeholders to quickly identify trends and derive actionable insights from large-scale entertainment data.
